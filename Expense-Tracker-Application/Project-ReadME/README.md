## Project Overview

This project is a cross-language application development assignment. The goal is to create the same application in two different programming languages and compare how each language handles the same core requirements.

Our team selected the **Expense Tracker Application**. The application allows a user to record, view, filter, and summarize personal expenses. Both the Python and C++ versions include the same core features so the two implementations can be compared fairly.

---

## Core Features

Both versions of the application include the following features:

- Add a new expense
- View all saved expenses
- Filter expenses by category
- Filter expenses by date
- View an expense summary
- Exit the application

Each expense includes:

- Date
- Amount
- Category
- Description
